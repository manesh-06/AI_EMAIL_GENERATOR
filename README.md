# 📧 AI Mail Generator

AI Mail Generator is a full-stack web application that uses **Generative AI** to compose professional, formal emails based on user input. It allows users to generate email content dynamically by simply providing key points or intent.

---

## 🚀 Features

- ✍️ Generate AI-powered formal email content
- 💬 User-friendly UI for input and editing
- 📦 API integration with GROQ for AI generation
- 📁 Full-stack project using React + Express

---

## 🛠️ Tech Stack

**Frontend**: React + Vite + TailwindCSS  
**Backend**: Node.js + Express  
**AI Provider**: GROQ API  
**Language**: JavaScript (ES6+)
